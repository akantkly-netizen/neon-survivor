# NEON SURVIVOR

A fast, neon synthwave top-down arena survival game. Single HTML file, no dependencies, no build step.

## Play

Open `index.html` in any modern browser, or play it online via GitHub Pages (see the repo's Pages link).

## Controls

| | Desktop | Mobile |
|---|---|---|
| Move | `W A S D` / arrow keys | Left side of the screen |
| Aim | Mouse | Right side of the screen |
| Fire | Hold left click | Drag on the right side |
| Dash | `Space` / `Shift` | DASH button |
| Pause | `P` / `Esc` | Auto-pauses when the tab is hidden |
| Mute | `M` | - |

## Features

- Endless waves with growing difficulty and a boss every 5th wave
- 4 enemy types (swarmer, dart, tank, shooter) plus bosses with bullet patterns
- XP orbs and level-ups with 3 random upgrades to pick from
- Dash with invincibility frames and cooldown
- Combo multiplier for fast kills
- Procedural sound effects (Web Audio) and particle effects
- High score saved in the browser (localStorage)
- Responsive: desktop and mobile touch controls

## Tech

Canvas 2D, vanilla JavaScript, Web Audio API.
